# AZ-802 Windows Server Administrator Associate lab exercises

This repository contains the lab instructions and supporting files for AZ-802 Windows Server Administrator Associate training.

The exercises support self-paced training and Microsoft authorized instructor-led training.

## Information for MCTs

**Are you an MCT?** - Have a look at our [GitHub User Guide for MCTs](https://microsoftlearning.github.io/MCT-User-Guide/)

Any MCT (Microsoft Certified Trainer) can submit a pull request for code or content in this GitHub repository. Microsoft and the course author triage submitted bugs, changes, improvements, and ideas.
